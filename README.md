# 海南旅行手册

2026 年 9 月 25–30 日，海口 → 三亚。

## 使用

下载 `index.html`，用浏览器打开。整份手册只有一个 HTML 文件，可直接分享。

- 每日行程：路线示意图、可展开的活动详情和前后一天切换。
- 预订与订单：酒店、交通、门票和预约事项。
- 行前打包：物品勾选、分装建议和出门复查。

勾选和备注保存在当前浏览器，点击“保存完整手册”可导出包含填写内容的副本。微信或文件预览可能限制脚本，请在浏览器中打开。

## 维护

直接修改 `index.html`；样式、脚本、地图和内容均包含在文件内，无构建步骤，无外部运行依赖。仓库用于存放文件，尚未配置网页托管。
